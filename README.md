# 🧠 Calm Routes

A navigation app that finds **quiet, smooth, and calm routes** for people with ADHD, sensory sensitivities, and other conditions.

## 💡 What It Does

Instead of just finding the fastest route, Calm Routes finds routes that are:
- **Quiet** - Less traffic noise
- **Calm** - Fewer traffic lights, less chaotic
- **Smooth** - Less visual stimulation
- **Peaceful** - Away from crowded areas

## 🎯 For ADHD Users

People with ADHD often struggle with overstimulation. This app helps by:
- Avoiding busy, noisy streets
- Suggesting routes with fewer distractions
- Showing quieter times to travel
- Highlighting calm rest areas along the way

## 🚀 Getting Started

1. Clone the repo
2. Run `npm install`
3. Run `npm start` to start the server
4. Open http://localhost:3000 in your browser

## 🔧 Tech Stack

- **Backend**: Node.js + Express
- **Frontend**: HTML, CSS, JavaScript
- **Maps**: Google Maps API
- **Database**: MongoDB (for storing routes and preferences)
